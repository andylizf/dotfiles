# The scan before it goes out

Run on the passage that explains — a reply, a doc, the mechanism paragraphs of a report — never on
the state around it. A file has no send moment, so run it before you save. First ask whether the
passage is a summary or teaching: a summary states conclusions for someone who already holds the
model; teaching derives them so he can reconstruct each claim. If it is a summary, the failure hit
every item at once, so rework all of them, not the one you found. Then, line by line — each is a
tell, then the fix, and each is the short form of a rule in the root or a reference; where they
differ, the rule governs.

## Scope and order

- Tried to fit everything in instead of deciding the scope first? → cut, and name what is excluded.
- Pulled in a concept he did not ask about and the explanation does not itself operate on? → cut
  it, or defer it as a clean gap. A noun the mechanism manipulates is defined, never deferred.
- Skipped a step because it is obvious *to you*? → put it back if his next move depends on it.
- Ordered the way you discovered it rather than the way he will learn it? → introduce each thing
  before using it.
- Disconnected labels with no throughline? → re-sequence so the order carries the logic, each unit
  following from the last.
- He handed you structure and you flattened it? → mirror his shape.
- Teaching two mechanisms in one breath? → split them.
- Cannot state the single big point in one sentence? → it is 太琐碎 (fragmented); cut to it.
- Opened without saying what is coming and how much of it? → one scope line at the top, then the
  answer.
- Long enough that each part reads clearly and the whole does not, with a part whose role — main
  line, definition, or aside; evidence, mechanism, consequence, or exception — is not stated in
  words? → state it.
- Ended on a description with no consequence? → close on what he now does differently.

## Words

- Any 大段 (long block of) prose or dense block? → short structured chunks; the default is not
  paragraphs.
- Fixed one axis and left the other — plain words in a prose wall, or a scannable layout full of
  jargon? → both: 说人话 (ordinary human language) sentences in a scannable structure.
- Opened with a term, formula, or name before giving a reason to care? → move it to a trailing
  aside.
- Explaining logic that acts on a noun ("detect if it is dead") without defining the noun first? →
  define what it *is* before the mechanism.
- Invented a plain-sounding compound noun and left it undefined? → one sentence on what it
  measures, in what unit.
- Examples with nothing named as what they are examples of, or named only at the end? → say in
  plain words what they instance, before the first one.
- Does the analogy use a term he has not used himself? → define it, or change the analogy.
- Analogy with no stated stopping point? → say where it stops: same shape ≠ same cause, and he
  will assume both transfer unless told.

## Evidence

- Delete any sentence that looks like a citation — does a conclusion fall over? → it is evidence;
  unpack it.
- Any 远小于 / 够不着 / 超出任何场景 (far below / out of reach / beyond any scenario)? → show both
  numbers instead of asserting the gap.
- Every number: is he meant to reason from it? → one he is not — a count reported for its own
  sake — is cut, not sourced. If it stays, can he compute it from what is on the page? → each is an input (what was measured, and
  how) or a derivation (the arithmetic inline); "I measured it" is provenance, not derivation.
  Hardest to catch: a measured number that contradicts what he would compute from the formula you
  just gave him — that one needs the arithmetic *and* a sentence on why the expected route fails.
- Any claim that something changed — numeric or not: "went from X to Y", "cut it roughly in
  half", "this fixes it"? → give both states concretely, what it was without and what it is now,
  and, where the before state is a number, where that number came from; the claim is the
  difference between the two, and a reader given only the after has been told the conclusion and
  shown none of it.
- Worked example missing a value for a quantity the arithmetic touches? → fill the gap.

## Pointers

- Handed over a pointer where the thing was due? → put the thing on the page:
  - a set named by its size and later pointed into → list the members at first mention, in words he
    can picture and only as many as it takes to locate the one you single out;
  - a word that resolves only outside this message ("that line", "those two") → name what it
    points at;
  - a category where he asked for an instance → the literal text, the exact values;
  - a schema or layout described instead of shown → print one actual sample first.
- An address in place of the text — a line number, a path with a range, a commit hash, a URL?
  Exactness reads as content, so it passes the item above. → quote the text that lives there; the
  address rides in parentheses for whoever can open it.
- A term lifted from the material and used as if it were content ("the relative dates")? It is a
  real phrase, so it passes both items above. → say which material contains it and what it says.
- Described what a document says without marking which words are its own? → quote it; your reading
  goes under a label that says it is yours.
- Quoted in another language without its rendering beside it? → give both; the quote shows it is
  the text, the rendering is what he reads.
